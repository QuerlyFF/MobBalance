# MobBalance

Плагин баланса ванильных мобов для SMP Cristalix.

**Платформа:** Paper 1.21.1  
**Java:** 21

## Текущая первая группа мобов

- Zombie (включая Baby Zombie)
- Zombie Villager
- Husk
- Drowned
- Skeleton
- Stray

## Баланс на HARD

Каждый поддерживаемый моб при разрешённом типе спавна получает один постоянный случайный ролл:

- здоровье: от +0% до +100% от базового;
- урон: от +0% до +100% от базового;
- шанс брони: ванильная база 15% × 8, cap 90%;
- шанс оружия Zombie-семейства: ванильная база 5% × 8, cap 40%;
- шанс зачарования брони: база 50% × 3.5, cap 75%;
- шанс зачарования оружия: база 25% × 3.5, cap 70%.

### Броня

При успешном ролле MobBalance выбирает 1–4 предмета и старается только улучшить уже существующую экипировку.
Вес материала по умолчанию:

- Leather — 20
- Gold — 25
- Chainmail — 25
- Iron — 25
- Diamond — 5

Экипировка, изменённая плагином, имеет 2% шанс выпадения.

### Drowned

Чтобы не сломать экономику трезубцами:

- 40% шанс усиленного оружия;
- внутри успешного ролла 50% Trident / 50% Iron Sword;
- итоговый дополнительный шанс Trident около 20%.

### Skeleton / Stray

Их стрелы используют выпавший мобу множитель урона. Дополнительно 35% стрел получают один случайный дебафф:

- Slowness I — 6 сек;
- Weakness I — 8 сек;
- Poison I — 5 сек;
- Wither I — 3 сек.

Все числа вынесены в `config.yml`.

## Команды

- `/mobbalance status` (`/mb status`) — показать активные шансы;
- `/mobbalance reload` (`/mb reload`) — перечитать конфиг.

Permission: `mobbalance.admin`.

## Сборка

```bash
mvn clean package
```

Готовый файл: `target/MobBalance.jar`.
